# RevivePSVR1 - WipEout v0.1.0

Initial Windows PCVR pre-release package. Download RevivePSVR1-WipEout-v0.1.0-Windows-PCVR.zip.
The player and importer are included; no compilation is required.

Extract the whole ZIP, add your own CUSA05670 base PKG and update 01.07 to
games, start your OpenXR runtime and open Play WipEout VR.bat.
No game, firmware or saves are included.

Rendering scales up to 200% are available for the supported executable.
Some tracks still show stretched geometry, incorrect vegetation or fog, and intermittent black-eye rendering. Not every championship, track or race-exit path is verified.
Back up pc-vr-tests/Wipeout/user before upgrading. Review collected logs before sharing.
