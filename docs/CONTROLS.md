# Controls

Use a PC gamepad or OpenXR VR controllers. Automatic input uses the active device.
With reduced-button VR controllers, hold Menu for the D-pad/touchpad mapping.
The launcher also supports a right-stick menu-navigation fallback; a physical
PC gamepad retains its independent inputs. Steam Frame has gamepad-style bindings.

Use Options/Start to pause or open the game menu. VR Menu maps to Options; hold
Options/Start for recentering. Device-specific testing is still required.
Report the active OpenXR interaction profile for a missing button or stick.
