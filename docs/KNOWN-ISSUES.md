# Known issues

Some tracks still show stretched geometry, incorrect vegetation or fog, and intermittent black-eye rendering. Not every championship, track or race-exit path is verified.

Higher rendering scales increase GPU and memory requirements. Changing scale
is not a guarantee that the headset's recommended resolution is matched.
A completed automated run is not proof of visual correctness or crash immunity.
Use consecutive frames/video to diagnose flicker. Keep validation layers and
capture diagnostics off for normal gameplay. Preserve previous saves when upgrading.
