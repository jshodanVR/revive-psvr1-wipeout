# Repository instructions

This is the standalone WipEout Windows PCVR/OpenXR project. Use English for
comments, documentation and user-facing messages. Never use Unicode U+2014.
Describe the project independently and preserve licenses and source attribution.
Use only this checkout for development unless the user requests migration cleanup.
Use the dedicated deploy key and verified local jshodanVR author/committer identity.
Never use personal authentication, default SSH keys or global Git identity.
Never commit games, extracted assets, saves, logs, private keys or build output.
Build with tools/build-wipeout.ps1. Keep accepted tags and release ZIPs immutable.
Report exact test scope; scheduled stops are not crashes. Do not claim complete
campaign or hardware compatibility from limited smoke tests.
